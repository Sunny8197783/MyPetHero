# 디자인 메모

## 디자인 브리프

- **약속**: 낮에는 귀여움받는 평범한 개, 밤에는 동네를 지키는 영웅. 주인은 끝까지 모른다(아마도).
- **느낌**: 낮은 따뜻하고 느긋하게, 밤은 시원하게 쓸어버리는 손맛. 둘 사이의 낙차에서 웃음이 난다.
- **주 동사**: 낮 — 고른다(행동 카드). 밤 — 움직인다(공격은 자동).
- **5~30초마다 반복하는 것**: 낮 — 행동 하나 고르고 결과 보기. 밤 — 무리를 끌어모아 터뜨리고 보석 줍기, 레벨업 카드 고르기.
- **1~5분에 걸쳐 바뀌는 것**: 낮 — 시간이 흐르고 피로가 쌓인다. 밤 — 적 구성과 밀도가 변하고, 보스가 오고, 새벽이 온다.
- **보상과 위험**: 강해지려면 낮에 무리해야 하지만 피로가 쌓이면 밤에 약해진다. 밤에 욕심내면(다침, 늦은 귀가, 마당 전투) 의심도가 오른다.
- **잘하는 플레이어는**: 피로를 관리하고, 집에서 떨어진 곳에서 싸우고, 새벽 전에 집 근처로 돌아온다.
- **이번 범위에서 뺀 것**: 온라인 랭킹, 여러 맵, 영구 성장(밤마다 무기는 새로 모은다).

## 코어 루프 계약

> 플레이어는 **낮에 행동을 골라** 스탯을 키우고, **밤에 움직여서** 몬스터를 처치한다.
> **피로와 의심도**가 위험을 만들고, 성공하면 **스탯·점수·다음 이야기**를, 실패하면 **의심도 상승과 약해진 다음 밤**을 받는다.

| 조항 | 코드에서 확인할 곳 |
|---|---|
| 동사가 실제 입력에 연결됨 | `ui/App.tsx` 행동 카드 → `director.doAction`, `core/input.ts` → `night/player.ts` |
| 목표가 화면에 보임 | 낮: 시계·스탯 바·의심도. 밤: 타이머·처치 수·보스 체력·"집으로" 화살표 |
| 첫 1분 안에 압박이 있음 | 밤 시작 직후 가까운 곳에 첫 무리, 30초 안에 첫 레벨업 |
| 보상이 상태를 바꿈 | `day/dayLogic.ts`(스탯), `night/levelup.ts`(무기·패시브), `data/index.ts: nightModifiers` |
| 실패가 이유를 알려 줌 | 결과 화면의 "아침에 주인이 눈치챌 것들" 목록 |
| 재시도가 빠름 | 기절해도 캠페인은 이어진다(의심도만 크게 오름) |

## 밤 전투 구성

- **공간**: 동네 11×11 타일(132×132 유닛), 3×3 도로망. 안쪽 네 블록은 놀이 공원, 숲 공원, 주차장, 묘지. 집은 북서쪽.
- **카메라**: 쿼터뷰 추적. 시야 가로 약 36유닛. 적은 시야 바로 밖(21~26유닛)에서 생긴다.
- **첫 결정**: 시작 지점이 집 앞마당이라, 바로 나가서 싸울지(마당 보호) 가까이서 싸울지(귀가 편함) 정한다.
- **고조**: `waves.json` 의 3구간으로 스폰 속도가 오르고, 중간중간 포위(ring)·측면(side) 습격, 일정 간격으로 엘리트.
- **보스**: 밤마다 1종. 돌진형, 내려찍기형, 탄막형, 혼합형, 최종(나선 탄막 + 내려찍기 + 소환). 공격 전에 바닥 경고가 뜬다.
- **쉬는 박자**: 레벨업 선택 화면(정지), 보스 처치 슬로모션, 새벽 귀가.

## 의심도

| 원인 | 수치 (`balance.json`) |
|---|---|
| 다친 정도 | 받은 피해 ÷ 최대 체력 × 14 (최대 14) |
| 늦은 귀가 | 새벽 10초 유예 뒤 초당 0.6 |
| 엉망이 된 마당 | 집 13유닛 안에서 처치한 수 × 0.25 (최대 8) |
| 기절 | +24 |
| 보스를 놓침 | +4 |
| 무피해 | −6 |
| 매일 아침 | −4 |

단계(0·25·50·75·100)마다 주인 얼굴 아이콘, 행동 뒤 대사, 저녁·아침 대사가 바뀐다.
75를 넘으면 GPS 목줄 이벤트(이후 늦은 귀가 벌점 1.5배), 100이면 "들킬 뻔한 순간" 컷씬과 시치미 떼기 미니게임.

## 컷씬을 추가하려면

`src/story/scripts.ts` 에 `Step[]` 을 돌려주는 함수를 추가한다. 단계 종류는 `CutscenePlayer.ts` 의 `Step` 타입에 있다.

```ts
export function myScene(): Step[] {
  return [
    { t: 'stage', id: 'house', sky: 'day', look: 'day' },
    { t: 'cam', pos: [3, 7, 9], look: [0.6, 1.2, 0.2] },
    { t: 'place', actor: 'owner', pos: [-0.4, 0.2], face: 0.9 },
    { t: 'say', who: 'owner', text: '호두야, 간식!' },
    { t: 'think', text: '(임무보다 급한 일이 생겼다.)' },
    { t: 'cam', pos: [2, 4, 5], look: [1.2, 0.8, 0.6], dur: 1.5 },
    { t: 'fade', to: 1, dur: 0.6 },
  ];
}
```

## 무기를 추가하려면

1. `weapons.json` 의 `weapons` 에 항목을 추가한다(`kind` 는 기존 8종 중 하나: nova, orbit, beam, boomerang, zone, bounce, chain, dash).
2. 새로운 동작이 필요하면 `night/weapons.ts` 의 `update()` 에 `kind` 분기를 추가한다.
3. 아이콘은 `ui/widgets.tsx` 의 `ICONS` 에 추가한다.
